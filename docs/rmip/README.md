# Research Methods in Practice snapshot

This directory contains a local snapshot of the Research Methods in Practice
pages referenced by Research Methods in R. The pages were retrieved on
2026-09-18 from <https://benwhalley.github.io/rmip/> so that this archive does
not depend on that site remaining online.

The snapshot preserves the original authorship and licensing information shown
on the pages. The original course was written by Ben Whalley, Andy Wills, and
other contributors and is distributed under a Creative Commons licence. This
snapshot is retained for archival and educational use with that attribution.

Some historical RMIP URLs no longer exist. Where the old Research Methods in R
materials referred to those paths, the links have been mapped to the closest
available local page in this snapshot.
